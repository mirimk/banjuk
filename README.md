# 반죽 (Banjuk)

> 빵을 만들수록 자신을 잃어가는 제빵사의 이야기
> 경영 시뮬레이션 + 스토리 어드벤처 + 심리 호러 · Godot 4 · 2D 픽셀아트 (현재 임시 도형 그래픽)

## 실행 방법

1. [Godot 4.3 이상](https://godotengine.org/download) 설치
2. Godot 프로젝트 매니저에서 **가져오기 → 이 폴더의 `project.godot`** 선택
3. `F5` (메인 씬: 타이틀 화면)

## 조작

| 입력 | 동작 |
|---|---|
| 마우스 클릭 (모바일: 터치) | 모든 조작 (스테이션, 빵, 버튼) |
| Space / Enter | 대화 넘기기, 반죽 미니게임 누르기 |
| Esc / 오른쪽 위 ⚙ | 설정 (저장 · 저장 후 종료 · 음량 · 음소거) |

## 현재 구현 범위 (v0.2 · 2일차까지)

- **타이틀**: 새 게임 / 이어하기(저장 파일이 있을 때) / 종료
- **설정(모든 화면)**: 저장, 저장 후 종료(타이틀로), 음량 슬라이더, 음소거 — 열려 있는 동안 게임 정지
- **하루 시간표** (게임 1분 = 실제 0.5초, 3시간 ≈ 90초)

| 시간 | 장소 | 할 수 있는 일 |
|---|---|---|
| 05:00–08:00 | 주방 | 빵 만들기만 |
| 08:00–11:00 | 빵집 | 손님 받기만 |
| 11:00–13:00 | 주방 | 쉬는 시간: 사장·크루와 스토리 (선택지 있음) |
| 13:00–15:00 | 주방 | 빵 만들기 |
| 15:00–18:00 | 빵집 | 손님 받기 (16시쯤 비밀스러운 손님 등장) |
| 18:00 | — | 퇴근 → 정산 → 집에서 번 돈으로 보상 1개 선택 → 다음 날 |

  시간이 되면 시계가 멈추고 이동 버튼이 켜진다. 테스트용으로 `시간 x3`, `건너뛰기` 버튼이 있다.
- **빵 만들기**: 반죽대(타이밍 3회) → 발효실(초록 구간에서 꺼내기) → 오븐(황금빛에서 꺼내기) → 식힘대(김이 다 빠지면 클릭) → 진열대. 세 점수 평균으로 S~F 등급, 등급에 따라 가격이 달라짐.
- **손님 받기**: 나이·인종·성별이 다양한 손님 12명. 원하는 빵을 진열대에서 클릭해 건넨다. 반죽 손상이 높을수록 반죽이의 변화를 눈치채는 대사가 나온다.
- **능력치**: 체력(낮으면 반죽 판정이 좁아짐) / 반죽 손상(반죽·오븐 작업으로 증가, 높으면 반죽 막대가 빨라지고 손에 반죽이 들러붙음) / 기분(높으면 팁) / 돈
- **집 보상**: 푹 자기(체력+, 반죽 손상 완전 복구) / 유튜브(체력·기분+, 손상 그대로) / 치킨 / 반죽 보습 스파 — 수치는 임시
- 2일차 밤이 지나면 임시 엔딩 (To be continued)

## 폴더 구조

```
assets/            에셋 (현재는 폰트 설정만, 그래픽은 코드로 그린 임시 도형)
data/dialogues/    story.json — 아침·쉬는 시간 대사 (코드 수정 없이 편집 가능)
scenes/main/       title, game(주방·빵집), day_end(정산·집), ending
scripts/systems/   GameState(상태·저장·전환), Sound(합성 사운드), game_data(밸런스·손님·보상), overlay_ui(설정·확인창·알림), art(임시 도형)
scripts/game/      game(하루 진행 규칙), kitchen_view, bakery_view, hud, knead_panel, bread_picker
scripts/dialogue/  대화창 (선택지 지원)
tests/             smoke_test.gd(2일 자동 플레이), screenshot.gd(화면 캡처)
web-prototype/     같은 내용의 HTML 프로토타입 (참고용)
docs/              개발 로그
```

## 자동 테스트

타이틀부터 2일차 엔딩까지 자동으로 플레이(중간에 저장→불러오기 포함)해 오류 없이 끝나는지 확인합니다.

```bash
godot --headless --fixed-fps 60 --path . -s res://tests/smoke_test.gd
```

`SMOKE OK: ending reached...` 가 출력되면 통과입니다.

주요 화면을 PNG 로 저장하려면 (창이 잠깐 열림):

```bash
godot --path . --fixed-fps 60 -s res://tests/screenshot.gd -- <저장할 폴더>
```

## 참고

- 저장 파일은 `user://save.json`, 설정은 `user://settings.json` (Windows: `%APPDATA%\Godot\app_userdata\반죽 (Banjuk)\`).
- Windows 빌드로 내보낼 때는 내보내기 설정의 **리소스 → 리소스가 아닌 파일 포함 필터**에 `*.json` 을 추가해야 대사 파일이 포함됩니다.
- 한글 표시는 현재 시스템 폰트(맑은 고딕)를 사용합니다. 픽셀 폰트는 무료 OFL 폰트인 Galmuri / DungGeunMo 등을 `assets/ui/` 에 넣고 `default_font.tres` 를 교체하면 됩니다.
