# 반죽 (Banjuk)

> 빵을 만들수록 자신을 잃어가는 제빵사의 이야기
> 경영 시뮬레이션 + 스토리 어드벤처 + 심리 호러 · Godot 4.7 · 2D 픽셀아트 (현재 임시 도형 그래픽)

## 실행 방법

1. [Godot 4.7 이상](https://godotengine.org/download) 설치 (4.7.2 에서 테스트)
2. Godot 프로젝트 매니저에서 **가져오기 → 이 폴더의 `project.godot`** 선택
3. `F5` (메인 씬: 타이틀 화면)

## 조작

| 입력 | 동작 |
|---|---|
| 마우스 클릭 · 드래그 (모바일: 탭 · 스와이프) | 모든 조작 (스테이션, 빵, 버튼, 미니게임) |
| Space / Enter | 대화 넘기기, 타이밍 반죽 누르기 |
| ← → 번갈아 | 문지르기 반죽 (키보드 대안) |
| Esc / 오른쪽 위 ⚙ | 설정 (저장 · 저장 후 타이틀로 · 저장 후 게임 종료 · 음량 · 음소거) |

## 현재 구현 범위 (v0.3 · 7일차까지)

- **타이틀**: 새 게임 / 이어하기(저장 파일이 있을 때) / 종료
- **설정(모든 화면)**: 저장, 저장 후 타이틀로, 저장 후 게임 종료, 음량, 음소거 — 열려 있는 동안 게임 정지
- **하루 시간표** (게임 1분 = 실제 0.5초, 3시간 ≈ 90초) — 7일 동안 반복

| 시간 | 장소 | 할 수 있는 일 |
|---|---|---|
| 05:00–08:00 | 주방 | 빵 만들기 |
| 08:00–11:00 | 빵집 | 손님 받기 + 배달 (3일차~) |
| 11:00–13:00 | 주방 | 쉬는 시간: 사장·크루와 스토리 (선택지 있음) |
| 13:00–15:00 | 주방 | 빵 만들기 |
| 15:00–18:00 | 빵집 | 손님 받기 + 배달 (16시쯤 검은 외투의 손님 등장) |
| 18:00 | — | 퇴근 → 정산 → 집에서 보상 1개 선택 → 다음 날 (7일차 후 엔딩) |

  시간이 되면 시계가 멈추고 이동 버튼이 켜진다. `시간 x3` 은 발효·굽기·손님 대기까지 모두 3배로 빠르게 한다(미니게임 제외).

### 빵 (날짜별 해금)

반죽 1판 = 빵 4개. 발효실 4칸(1차·2차 발효 공용), 성형대 2칸, 오븐 3칸, 식힘대 4칸.


| 단계 | 해금 | 빵 | 공정 |
|---|---|---|---|
| 1단계 | 1일차 | 크림빵, 단팥빵, 초코소라빵, 소보루빵 | 반죽 → 발효 → 굽기 → 식히기 |
| 2단계 | 3일차 | 소시지빵, 고로케, 샌드위치 | 반죽 → 발효 → **성형** → 굽기 → 식히기 |
| 3단계 | 5일차 | 치아바타, 바게트, 통밀빵 | 반죽 → 발효 → 성형 → **2차 발효** → 굽기 → 식히기 (**발효종 필요**) |

- 단계가 높을수록 값이 비싸지만 체력 소모·반죽 손상이 크다 (`game_data.gd` 의 `TIERS`).
- **공정 생략**: 발효 뒤 성형/2차 발효를 건너뛰고 바로 오븐에 넣거나, 덜 식은 빵을 진열할 수 있다. 빵은 나오지만 등급은 최하(F).
- **발효종(르방)**: 2일차 오후에 검은 외투의 손님이 준다. 손님을 놓쳐도 퇴근길 문 앞에 놓여 있다.

### 미니게임 (모두 마우스·터치로 가능)
- **반죽 – 타이밍**: 빨간 막대가 초록 구간에 왔을 때 3번 탭 (Space 가능)
- **반죽 – 문지르기**: 5초 안에 반죽을 좌우로 문질러 게이지 채우기 (드래그 / ← →)
- **성형 – 따라 그리기**: 빵마다 다른 점선 모양(지그재그·타원·네모·접기·칼집·원)을 손가락으로 따라 그리기
- **발효·굽기·식히기**: 게이지의 초록 구간에서 탭
- 체력이 낮으면 판정이 좁아지고, 반죽 손상이 높으면 막대가 빨라지고 손이 떨린다.

### 빵집
- **3단 진열대**: 단계별 선반이 날짜에 따라 해금. 빵은 종류마다 그림 하나 + 개수(x3)와, 다음에 나갈 빵의 등급 배지로 표시. 아직 해금되지 않은 선반은 '잠김'. 진열 개수 제한 없음.
- **등급별 가격**: S ×1.6 · A ×1.3 · B ×1.0 · C ×0.7 · F ×0.4. 진열대에는 다음에 나갈 빵의 값이, 식힘대·빵 선택 창에도 등급별 값이 표시된다.
- **빨리 건네면 팁**: 손님 대기 게이지가 80% 이상 남았을 때 건네면 빵값의 30%, 60% 이상이면 15% 를 팁으로 받는다 (기분 70 이상이면 +300원 추가).
- **품절 패널티**: 손님이 찾는 빵이 진열대에 없어서 그냥 돌아가면(죄송해요 / 기다리다 떠남) 일당에서 5,000원 차감 (`SOLD_OUT_PENALTY`).
- **대기 초과 패널티**: 빵은 있었는데 늦게 줘서 손님이 기다리다 떠나면 일당에서 3,000원 차감 (`LATE_PENALTY`).
- **손님**: 손님이 2~5초 간격으로 들어온다(날이 갈수록 더 빠르게). 대기 게이지가 날마다 짧아진다(13초 → 9.4초). **엉뚱한 빵을 주면** 인내심 -30% · 기분 -3, 3번 틀리면 화내고 나간다.
- **배달 (3일차~)**: 라이더가 주문표(빵 2~3개)를 들고 오면 진열대에서 해당 빵을 탭해 담는다. 다 담으면 출발, 수수료 30% 를 뗀 금액만 받는다. 시간이 지나면 취소(담은 빵은 진열대로 복귀).
  탭한 빵은 카운터 손님이 원하면 손님에게, 아니면 배달 주문에 필요하면 배달 봉투에 자동으로 들어간다.
- **빵 먹기**: 체력이 바닥나면 아래 `빵 먹기` 로 진열대 빵(또는 사장님 빵)을 먹어 체력 회복. **비싼 빵일수록 많이 회복**(빵값 125원당 체력 +1, 10~60). 빵값만큼 일급에서 차감 (소지금이 모자라면 빚). 정산 화면에 '먹은 빵(일급에서 차감)' 으로 표시.

### 퇴근 후 보상 (하나 선택)

| 보상 | 값 | 효과 |
|---|---|---|
| 푹 자기 | 무료 | 체력 +35, 반죽 손상 -40 |
| 유튜브 보기 | 무료 | 체력 +45, 기분 +20 |
| 치킨 시켜먹기 | 30,000원 | 체력 +60, 기분 +30, 반죽 손상 -20 |
| 반죽 보습 스파 | 100,000원 | 체력 +70, 기분 +15, 반죽 손상 -60 |

반죽 손상은 완전히 복구되지 않고 다음 날로 이어진다. 소지금이 마이너스여도 무료 보상은 고를 수 있다.

### 기분 (0~100)

- 오름: 빨리 건네기 +1, S등급 판매 +2, 유튜브 +20, 치킨 +30, 스파 +15, 르방 돌보기 +10
- 내림: 손님이 그냥 떠남 -3, 빵 잘못 건넴 -3(3번이면 추가 -2), 죄송해요 -1, 배달 취소 -3
- 효과: 70 이상이면 손님마다 팁 +300원 / 50 미만이면 미니게임 판정 구간 15% 좁아지고 손님 등장 간격 1.25배, 30 미만이면 30% 좁아지고 1.6배 / 7일 평균 40 미만이면 '나만의 빵' 엔딩을 볼 수 없다 ('문 밖의 새벽')

### 이야기 · 엔딩
- 3일차 직원 명부, 4일차 크루의 고백, 5일차 발효종 선택, 6일차 정식 직원 제안, 7일차 마지막 선택 (`data/dialogues/story.json`)
- 엔딩 4종: **나만의 빵** / **반쯤 남은 손** / **문 밖의 새벽** / **명부의 마지막 줄** — 마지막 선택, 르방을 지키고 키웠는지, 7일간 매일 밤 반죽 손상의 평균(55 이상이면 '반쯤 남은 손'), 기분 평균(40 미만이면 '문 밖의 새벽')으로 갈린다. 크루의 말처럼 너무 열심히 하면 좋은 결말을 보기 어렵다.

## 폴더 구조

```
assets/            에셋 (현재는 폰트 설정만, 그래픽은 코드로 그린 임시 도형)
data/dialogues/    story.json — 아침·쉬는 시간 대사 (코드 수정 없이 편집 가능)
scenes/main/       title, game(주방·빵집), day_end(정산·집), ending
scripts/systems/   GameState(상태·저장·전환), Sound(합성 사운드), game_data(밸런스·손님·보상), overlay_ui(설정·확인창·알림), art(임시 도형)
scripts/game/      game(하루 진행 규칙), process(공정 규칙), kitchen_view, bakery_view, hud,
                   knead_panel(타이밍·문지르기), shape_panel(성형 따라 그리기), bread_picker
scripts/dialogue/  대화창 (선택지 지원)
tests/             smoke_test.gd(7일 자동 플레이), load_all.gd(스크립트 오류 검사), screenshot.gd(화면 캡처)
web-prototype/     v0.2 시점의 HTML 프로토타입 (참고용, 3일차 이후 내용은 없음)
docs/              개발 로그
```

## 자동 테스트

모든 스크립트에 문법 오류가 없는지:

```bash
godot --headless --path . -s res://tests/load_all.gd
```

타이틀부터 7일차 엔딩까지 자동 플레이 (저장→불러오기, 성형·2차 발효, 공정 생략 F 등급, 빵 잘못 주기, 빵 먹기, 배달을 모두 거치는지 확인):

```bash
godot --headless --fixed-fps 60 --path . -s res://tests/smoke_test.gd -- 0   # 적당히 일하고 르방을 지키는 경로 → '나만의 빵'
godot --headless --fixed-fps 60 --path . -s res://tests/smoke_test.gd -- 1   # 쉬지 않고 일하고 명부에 이름을 올리는 경로 → '명부의 마지막 줄'
```

`SMOKE OK: ending=...` 가 출력되면 통과입니다.

주요 화면을 PNG 로 저장하려면 (창이 잠깐 열림):

```bash
godot --path . --fixed-fps 60 -s res://tests/screenshot.gd -- <저장할 폴더>
```

## 빌드 (내보내기)

`export_presets.cfg` 에 **Web**(스레드 없음)과 **Windows** 프리셋이 있다. Godot 4.7.2 내보내기 템플릿을 설치한 뒤:

```bash
godot --headless --path . --export-release "Windows" build/windows/Banjuk.exe   # pck 내장 단일 exe
godot --headless --path . --export-release "Web" build/web/index.html
python3 tools/web_postprocess.py build/web   # claude.ai 아티팩트로 올릴 때만: 엔진 분할 + pck 를 JS 로 변환
```

- 웹에서는 시스템 폰트(맑은 고딕)를 쓸 수 없어서 `assets/ui/NotoSansKR-Subset.otf`(Noto Sans CJK KR 한글·기호 부분 집합, OFL)를 대체 폰트로 넣었다. PC 에서는 계속 맑은 고딕이 먼저 쓰인다.
- 설정의 ⚙ 아이콘은 글꼴에 없는 경우가 있어 도형으로 그린다.

## 참고

- 저장 파일은 `user://save.json`, 설정은 `user://settings.json` (Windows: `%APPDATA%\Godot\app_userdata\반죽 (Banjuk)\`).
- 내보내기 프리셋에는 대사 파일(`*.json`) 포함 필터가 이미 들어 있습니다.
- 한글 표시는 현재 시스템 폰트(맑은 고딕)를 사용합니다. 픽셀 폰트는 무료 OFL 폰트인 Galmuri / DungGeunMo 등을 `assets/ui/` 에 넣고 `default_font.tres` 를 교체하면 됩니다.
