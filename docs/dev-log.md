# 개발 로그

## 2026-11-15 · v0.2 — 2일차까지 하루 루프

같은 날 HTML 로 먼저 만든 프로토타입(`web-prototype/`)을 Godot 로 그대로 옮겼다.

### 구현
- 타이틀: 새 게임 / 이어하기 / 종료
- 모든 화면에 설정 버튼(⚙, Esc): 저장 · 저장 후 종료 · 음량 · 음소거. 저장은 `user://save.json`
- 하루 시간표: 05–08 빵 만들기 / 08–11 영업 / 11–13 쉬는 시간 스토리 / 13–15 빵 만들기 / 15–18 영업 → 정산 → 집 보상 → 다음 날
- 빵 만들기 미니게임: 반죽(타이밍 3회) → 발효(구간) → 굽기(색) → 식히기(김) → 진열대, S~F 등급
- 손님 받기: 다양한 손님 12명 + 비밀스러운 손님(검은 외투, 오후 16시). 반죽 손상에 따라 대사 단계 변화
- 정산 영수증, 집 보상 4종(1개 선택), 2일차 후 임시 엔딩
- 사운드: 효과음·배경음을 코드로 합성 (임시)
- 테스트: 2일 자동 플레이 스모크 테스트, 화면 캡처 스크립트

### v0.1 대비 변경
| 항목 | v0.1 | v0.2 | 비고 |
|---|---|---|---|
| 진행 방식 | 좌우 이동 + E 상호작용 | 클릭(터치) 기반 화면 전환 | 모바일 대응 고려 |
| 반죽 미니게임 | ← → 연타 + Space '온 힘을 다해' | 타이밍 3회 판정 | 요청 사양. '온 힘' 아이디어는 추후 재도입 후보 |
| 능력치 | 돈·체력·기억·신체·오염도 | 돈·체력·반죽 손상·기분 | 요청 사양. 기억/신체는 3일차 이후 스토리와 함께 재검토 |

### 기획서 대비 변경/추가 (제안 상태, 확정 아님)
| 항목 | 기획서 | 구현 | 이유 |
|---|---|---|---|
| 희생의 발생 방식 | 품질이 높을수록 자동으로 희생 | 플레이어가 **Space(온 힘을 다해)** 로 직접 더 내어줄지 선택. 누르는 동안 반죽이 속삭임 | "스스로 희생하는 사람에게 반죽은 더 빠르게 반응한다"는 세계관 규칙을 조작으로 체험하게 함. 플레이어가 공범이 됨 |
| 크루 외형 | 크루아상 | 오른쪽 끝 마디만 색이 바래 있음 | 이미 일부를 빼앗겼다는 복선 |
| 손님 대사 | - | 품질이 낮으면 "전에 있던 아저씨 빵이 더 폭신했어요" | 과거 직원(직원 명부) 복선 |

### 수치 (임시, 밸런스 미조정)
- 일당 = 50 + 품질/2
- 체력 −(12 + 힘준비율×25), 오염도 +(2 + 품질/10 + 힘준비율×15), 신체 −(힘준비율×8)
- 체력이 낮으면 반죽 효율 0.6배까지 감소 (2일 차부터 의미 있음)
