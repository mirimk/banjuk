### 요청 반영
1. 설정 창에 `저장 후 게임 종료` 추가 (기존 '저장 후 종료(타이틀로)'는 `저장 후 타이틀로`로 이름 변경). 타이틀은 새 게임 / 이어하기 / 종료 유지
2. 7일차까지. 1–2일차 1단계 빵(크림빵·단팥빵·초코소라빵·소보루빵), 3–4일차 2단계(소시지빵·고로케·샌드위치) 추가, 5–7일차 3단계(치아바타·바게트·통밀빵) 추가. 기존 식빵·크루아상·바게트·베이글은 새 목록으로 교체
3. 단계별 공정: 1단계 반죽→발효→굽기→식히기 / 2단계 +성형 / 3단계 +성형+2차 발효(발효종 필요). 공정을 건너뛰어도 빵은 나오지만 품질 상한 20(F)
4. 진열대 3단 선반(단계별 해금), 종류별 그림 1개 + 개수, 다음에 나갈 빵 등급 배지
5. 2일차 검은 외투의 손님이 르방(발효종)을 줌 (놓치면 퇴근길 문 앞에서 획득)
6. 3일차부터 배달 주문 (영업 시간대마다 3–4일차 1건, 5–6일차 2건, 7일차 3건), 수수료 30%
7. 빵 먹기: 체력 회복(빵값에 비례, 아래 추가 수정 참고), 빵값만큼 일급에서 차감. 진열대가 비면 사장님 빵(3,000원 · +20)
8. 손님 대기 게이지 20초 → 13초(1일차)~9.4초(7일차). 잘못 준 빵: 인내심 -30%, 기분 -3, 3번이면 손님이 화내고 나감
9. 새 미니게임: 반죽 '문지르기'(드래그/스와이프), 성형 '따라 그리기'(터치로 점선 따라 그리기). 모두 탭·드래그만으로 가능

### 추가 수정 (같은 날)
- 타이틀의 `저장 후 종료` 제거 → 새 게임 / 이어하기 / 종료 (저장 후 종료는 설정 창에서)
- 손님 등장 간격 단축: 6~9초 → 3.3~5.2초(1일차), 7일차 2.1~3.5초. 영업 시작 후 첫 손님 1초
- 진열대 개수 제한 삭제 (선반 꽉 참 알림 없음)
- 진열대 선반의 '1단/2단/3단'·개수 표시 삭제, 해금 전 선반은 '잠김'만 표시
- 빵 먹기 회복량을 빵값에 비례하도록 변경 (125원당 체력 +1, 최소 10 · 최대 60). 진열대의 종류·등급별로 골라 먹을 수 있음
- 등급별 가격 배율 조정 S1.5/A1.2/B1.0/C0.7/F0.3 → S1.6/A1.3/B1.0/C0.7/F0.4, 진열대·식힘대·빵 선택 창에 값 표시
- 빨리 건네면 팁: 대기 게이지 80%↑ 빵값의 30%, 60%↑ 15% (정산에 '빨리 건넨 손님' 수 표시)
- 생산량 확대: 반죽 1판 2개 → 4개, 발효실 3칸 → 4칸, 오븐 2칸 → 3칸 (손님 수에 비해 빵이 모자라던 문제)
- 품절 패널티: 찾는 빵이 없어 손님이 그냥 돌아가면 일당 -2,000원 (정산에 표시)
- 퇴근 후 보상에서 반죽 손상 완전 복구 삭제: 푹 자기 -100 → -40, 스파 -100 → -60, 치킨 -15 → -20. 손상이 다음 날로 이어지므로 오븐 손상을 2단계 2 → 1, 3단계 3 → 2 로 낮춤
- 패널티 강화: 품절 2,000 → 5,000원, 빵은 있었는데 늦어서 떠난 손님도 3,000원 차감
- 보상 가격 인상: 치킨 15,000 → 30,000원, 스파 25,000 → 100,000원. 소지금이 마이너스여도 무료 보상(푹 자기·유튜브)은 선택 가능 (이전엔 진행이 막히는 버그)
- 기분 효과 추가: 50 미만이면 미니게임 판정 15%↓·손님 간격 1.25배, 30 미만이면 30%↓·1.6배. 빨리 건네면 기분 +1. 엔딩 '나만의 빵'에 7일 기분 평균 40 이상 조건 추가 (미달이면 '문 밖의 새벽')
- 웹 빌드용 한글 대체 폰트 포함, ⚙ 아이콘을 도형으로 그림, Web·Windows 내보내기 프리셋 추가

- 모든 화면에 설정 버튼(⚙, Esc): 저장 · 저장 후 종료 · 음량 · 음소거. 저장은 `user://save.json`

- 정산 영수증, 집 보상 4종(1개 선택), 2일차 후 임시 엔딩
- 사운드: 효과음·배경음을 코드로 합성 (임시)
