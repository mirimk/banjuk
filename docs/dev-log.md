### 기획서 대비 변경/추가 (제안 상태, 확정 아님)
| 항목 | 기획서 | 구현 | 이유 |
|---|---|---|---|
| 희생의 발생 방식 | 품질이 높을수록 자동으로 희생 | 플레이어가 **Space(온 힘을 다해)** 로 직접 더 내어줄지 선택. 누르는 동안 반죽이 속삭임 | "스스로 희생하는 사람에게 반죽은 더 빠르게 반응한다"는 세계관 규칙을 조작으로 체험하게 함. 플레이어가 공범이 됨 |
| 크루 외형 | 크루아상 | 오른쪽 끝 마디만 색이 바래 있음 | 이미 일부를 빼앗겼다는 복선 |
| 손님 대사 | - | 품질이 낮으면 "전에 있던 아저씨 빵이 더 폭신했어요" | 과거 직원(직원 명부) 복선 |

### 수치 (임시, 밸런스 미조정)
- 일당 = 50 + 품질/2
- 체력 −(12 + 힘준비율×25), 오염도 +(2 + 품질/10 + 힘준비율×15), 신체 −(힘준비율×8)
- 체력이 낮으면 반죽 효율 0.6배까지 감소 (2일 차부터 의미 있음)
